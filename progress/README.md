# progress

Specifications and AI notes for the feature in progress on the current branch: research reports,
action plans, decisions and their outcomes.

- The files here belong to the branch that created them. Name them after the feature and what they
  hold (e.g. `e2e_research.md`, `e2e_level_a_plan.md`).
- They are working notes, not documentation. Whatever must outlive the branch (architecture,
  conventions, how to run things) goes to `docs/architecture.md` or next to the code.
- Before the branch is merged, delete its files from this folder. On `main`, this README is the
  only file here.
